Aperçu de votre signature

Pour Outlook : cliquez sur « Copier la signature », puis dans Outlook ouvrez Fichier → Options → Courrier → Signatures, créez une nouvelle signature et collez (Ctrl+V).
Pour Gmail : Paramètres → Voir tous les paramètres → onglet Général → Signature → collez dans l'éditeur.
